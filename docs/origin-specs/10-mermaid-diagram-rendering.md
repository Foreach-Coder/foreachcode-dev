# Mermaid 图表渲染

- 需求 ID：`ORIGIN-10`
- 类型：跨版本需求
- 状态：OpenCode v1.18.18 已完成实现与专项验收
- 产品：`BluedCode Desktop` 与会话 HTML 导出

## 目标与用户场景

助手在正文中使用 Mermaid 描述流程、时序、状态或结构关系时，用户应直接看到图表，不必复制源码到其他网站。用户将会话导出为 HTML 后，接收方也应在离线浏览器中看到相同内容，同时保留原始会话 JSON 和 Mermaid 源码。

## 语法与范围

- 只识别 Markdown 围栏代码块。围栏信息字符串的第一个词忽略大小写后必须等于 `mermaid`。
- 原始 HTML 中的 Mermaid 容器、普通代码块、`.mmd` 附件和未进入 Markdown 正文渲染链路的文本不解释为图表。
- 正在流式生成且尚未闭合的 Mermaid 围栏按普通代码块展示；围栏闭合后才开始渲染。
- 使用完整 Mermaid 能力，不以缺少 Mindmap、Architecture 等图表类型的裁剪运行库冒充完整支持。

## 用户可见行为

- 应用内正文将有效 Mermaid 围栏替换为独立图表卡片。图表在正文宽度内居中，过宽内容只在卡片内部横向滚动，不撑宽会话页面。
- 图表卡片提供“复制 Mermaid 原文”操作，复制围栏内部的代码文本，不包含围栏标记；空白、缩进和换行与普通代码块的复制结果一致。成功状态不得改变复制内容。
- 图表卡片提供缩小、复位和放大操作，缩放范围为 50% 至 200%，每次按 25% 调整；放大后可用鼠标或触控拖拽平移。复位恢复 100% 和初始位置，视图交互不修改 Mermaid 原文或会话数据。
- 成功渲染时不重复展示源码，也不提供常驻的源码展开区域。
- 解析、资源限制或安全过滤失败时，图表位置显示明确失败状态，并回退为包含完整源码和复制操作的普通代码块；其他正文继续显示。
- 应用内图表跟随当前明暗主题。当主题改变时，已有图表使用对应主题重新生成，不沿用颜色错误的快照。
- 图表应具有辅助技术可读的名称。源码提供 Mermaid 标题或可访问描述时优先使用；否则使用本地化的通用名称。
- 多个图表按文档顺序稳定显示。重复内容和重新挂载不得造成持续闪烁、重复图表或无界缓存增长。

## HTML 导出行为

- 导出操作在本地使用与应用内相同的 Mermaid 渲染服务，将有效图表预渲染为经过安全过滤的浅色 SVG 快照。
- HTML 继续内嵌与 JSON 导出数据意义一致的完整原始会话 JSON；不得把图表快照写回或替换原始消息 Part。
- 派生快照保存在独立展示数据中，并以 Mermaid 原文摘要关联。公共 HTML 渲染器解析原始 JSON 后使用对应快照呈现图表。
- 导出的 HTML 不携带 Mermaid 运行库，不依赖 CDN、网络请求、业务 API 或本机已安装的 BluedCode。
- 快照缺失、摘要不匹配或无法安全解析时，离线页面回退为原始 Mermaid 代码块，不尝试联网补充渲染。
- 导出页的图表卡片同样提供“复制 Mermaid 原文”、缩放复位和拖拽平移，并遵循 `ORIGIN-09` 的单文件、安全、移动端和 `CodeAgent` 展示要求。

## 数据与性能不变量

- Mermaid 渲染只产生展示派生物，不修改持久化会话、模型输出、JSON 导出或后续上下文。
- 普通 Markdown 和不含 Mermaid 的会话不得加载 Mermaid 运行库，也不得因该能力固定增加每个 HTML 文件的运行库体积。
- 应用按 Mermaid 原文、主题和渲染器版本缓存安全结果。缓存必须有明确容量上限，并可在组件销毁或淘汰时释放。
- 使用 Mermaid 的默认资源边界：单图源码最多 50,000 个字符、最多 500 条边。超限按渲染失败处理，不静默截断原文。
- 流式生成过程中不得按 token 反复解析或布局 Mermaid 图表。

## 安全边界

- Mermaid 源码、标题、描述、节点文本、链接和配置均视为不可信数据。
- Mermaid 必须以 `securityLevel: "strict"`、`startOnLoad: false`、`htmlLabels: false` 初始化，禁止点击回调和运行时绑定函数。
- 图表内配置不得降低安全级别、扩大文本或边数限制、启用 HTML 标签、覆盖站点主题或注入自定义 CSS。
- Mermaid 返回的 SVG 必须再次经过专用 SVG 清理与验证。脚本、事件属性、`foreignObject`、iframe、嵌入对象、可交互链接、外部资源引用和可发起网络请求的 CSS 均不得进入应用 DOM 或导出文件。
- 图表渲染失败不得输出解析器堆栈、内部路径或未经清理的 SVG；日志不得记录完整用户图表源码。
- 打开导出的 HTML 不得因图表自动发起任何网络请求。

## 验收标准

1. 应用内已完成的 `mermaid` 围栏渲染为图表，普通和未闭合代码围栏保持代码展示。
2. 流式围栏闭合后从代码平稳切换为图表，不按 token 重复渲染。
3. 图表在明暗主题、窄窗口、长标签、宽流程图和同一正文多图场景下可读且不撑宽页面；缩放、复位和拖拽平移在应用与导出页中可用。
4. 应用与导出页均能复制未经改写的 Mermaid 原文；成功图表不重复显示源码。
5. 语法错误、50,000 字符、500 条边、安全过滤失败和缺失导出快照均回退完整源码，不影响相邻正文。
6. 导出 HTML 在断网和 `file://` 下直接显示预渲染图表，不包含 Mermaid 运行库，内嵌会话 JSON 与原始数据一致。
7. HTML、脚本、事件、危险 URL、配置覆盖和外部资源用例不会执行代码或产生自动网络请求。
8. 不含 Mermaid 的生产会话路径通过修改前后性能对比；当前版本通过功能测试、真实 Playwright 视觉检查和 BluedCode 构建兼容审计。

## 非目标

- 不提供 Mermaid 编辑器、实时预览、下载图片或重新运行图表的交互。
- 不渲染原始 HTML Mermaid 容器或 `.mmd` 附件。
- 不启用 Mermaid 点击指令、JavaScript 回调、外部图标包或远程字体。
- 不把成功图表的源码默认展开在正文中。
- 不让导出文件携带 Mermaid 运行库或打开后重新解析图表。
