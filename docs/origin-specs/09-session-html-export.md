# 会话 HTML 单文件导出

- 需求 ID：`ORIGIN-09`
- 类型：跨版本需求
- 状态：OpenCode v1.18.18 实现及专项验收通过；详见版本落地 spec
- 产品：BluedCode Desktop

## 目标与用户场景

用户将会话导出为一个 HTML 文件，通过自己选择的渠道交给其他人。接收方无需安装产品、登录账号或启动服务，使用现代浏览器即可离线阅读。现有 JSON 导出继续可用。

## 用户可见行为

- 会话导出入口提供 HTML 格式，导出完整会话而非仅当前屏幕加载的消息。
- 页面展示会话标题、时间、用户消息、助手正文和附件说明。Markdown 标题、列表、表格、引用及代码块保持可读。
- 助手按所回应的用户提问归为一次答复，内部多次思考、工具调用和正文按原有顺序在同一卡片展示，只显示一次身份与开始时间；不同提问的答复不混合。归组只影响展示，不改写原始消息数据。
- 只提交批注时也展示被引用的原文和批注内容，不出现空白用户气泡。助手正文中的有效批注标记显示为可跳转至对应批注的引用；不同提问的批注编号互不干扰，代码、引用示例和未知标记保留原文。
- 工具输入、输出、失败信息和推理记录可展开阅读，默认折叠；导出时未完成的过程保持其快照状态。
- 交互提问默认以独立问题卡片展示问题、选项和已记录的回答，支持多题、多选和自定义答案；无需展开原始工具数据即可阅读。尚未回答或没有保存回答的情况明确区分，原始输入输出仍可折叠查看。
- 已包含在会话数据中的内嵌图片可离线展示；本地文件及远程资源显示说明，不自动读取本机文件或下载网络资源。
- 页面提供代码复制、下载原始 JSON，并适配桌面和手机。没有消息时显示明确空态。
- 视觉参考根仓 `docs/design/ui/DESIGN.md` 的共用视觉基础和对话专章，采用浅灰分层背景、蓝色强调、用户气泡与助手自然排版。

## 数据与交付不变量

- HTML 内嵌与 JSON 导出相同结构的完整会话数据，数据与展示分离；从页面下载的 JSON 在数据意义上与嵌入数据一致。
- 公共渲染器及样式在仓库中统一维护，导出时内嵌。接收方不依赖 CDN、业务 API、远程字体或外部脚本。
- 导出文件记录格式和渲染器版本；旧文件不会因产品更新而被远程改变。
- 折叠只是阅读方式，不从原始数据删除工具信息、路径或其他元数据。

## 安全与业务边界

- 本地文件导出不调用公共分享、上传或遥测服务，不改变企业产品的公共分享策略。
- 消息、标题、附件、工具输出和 JSON 内嵌文本均视为不可信内容；不得执行其中的 HTML、脚本或危险 URL。
- 页面打开时不自动发起网络请求。普通网页链接仅由读者主动点击打开。
- 不自动读取链接所指向的本地文件；只内嵌原有会话中的安全栅格图片数据。

## 验收标准

1. 现有 JSON 导出仍可使用，HTML 导出的文件可独立离线打开。
2. 用户/助手消息、Markdown、折叠过程、附件说明和空态正确显示。
3. 导出超出当前可视范围的完整会话，长文本、代码和表格不会撑宽手机页面。
4. JSON 包含脚本结束标签、恶意 HTML 和危险链接时，数据完整且不会执行或自动联网。
5. 页面下载的 JSON 与原始会话数据一致，复制操作给出成功或失败反馈。
6. 当前版本通过相关功能测试、生产性能对比和 BluedCode 构建兼容审计。
